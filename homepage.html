TingleBox Uploader

TingleBox Uploader is a private tool that uploads videos to the owner's own YouTube channels (TingleBox and Visual Crafts) using the YouTube Data API.

It is not a public service: there are no public sign-ups, and only the owner's own Google accounts can use it. Videos are uploaded only when the owner directs an upload, and only to the owner's own channels.

The app uses a single Google permission: uploading videos to YouTube (youtube.upload). It does not read private channel data, and it does not access any other Google service.
